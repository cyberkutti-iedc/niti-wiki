# **NITI: Embedded Rust Framework**

**NITI** is a cutting-edge framework designed for seamless embedded Rust development. Built around the **NITI V1 Development Board**, it leverages the power of Rust for creating robust and efficient firmware solutions. 

### **Core Features**
- **Simplified Development:** Start quickly with pre-configured templates and examples using the [`niti-hal`](https://github.com/cyberkutti-iedc/niti-hal) library.
- **Comprehensive Tooling:** Supports project setup, building, and flashing firmware via intuitive commands.
- **Rust and AVR Ecosystem:** Full integration with the Rust ecosystem, optimized for AVR microcontrollers.
